# Performance Testing

Performance depends on the complete workload.

Record:

```text
GPU:
CPU:
RAM:
Windows version:
GPU driver:
Input resolution:
Output resolution:
Input FPS:
Output FPS:
AI models:
Video duration:
Processing time:
```

Important variables include GPU architecture, GPU memory, driver, source/output resolution, frame rate, model, number of AI stages and video codec.

Use measured results rather than claiming a particular processing speed for all Intel, AMD or NVIDIA hardware.
