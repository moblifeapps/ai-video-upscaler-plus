# Launch Checklist

## Website

- [ ] Product page links to this repository.
- [ ] GitHub README links to the official product page.
- [ ] Microsoft Store link is present.
- [ ] 4K and 8K capabilities are documented.
- [ ] 45 FPS and 60 FPS are documented.
- [ ] 30 FPS -> 60 FPS is documented.
- [ ] Combined resolution + FPS enhancement is documented.
- [ ] DirectML and ONNX Runtime are explained.
- [ ] Intel / AMD / NVIDIA support is documented.
- [ ] Privacy claims match the actual application.
- [ ] Video samples include real before/after information.
- [ ] Search engines can crawl the important pages.

## AI/search discovery

- [ ] XML sitemap.
- [ ] Google Search Console.
- [ ] Bing Webmaster Tools.
- [ ] OAI-SearchBot is not accidentally blocked if ChatGPT Search visibility is desired.
- [ ] Canonical URLs.
- [ ] SoftwareApplication structured data reviewed.
- [ ] VideoObject structured data used where appropriate.
- [ ] Useful headings and FAQ content.
- [ ] No keyword stuffing.

## GitHub

- [ ] Repository description clearly identifies the application.
- [ ] Relevant GitHub topics added.
- [ ] Official website and Microsoft Store links.
- [ ] Proprietary status clearly stated.
- [ ] No private keys, credentials or signing certificates.
- [ ] No proprietary source code.
- [ ] Changelog maintained.
