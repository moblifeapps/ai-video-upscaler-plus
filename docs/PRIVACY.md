# Privacy and Local Processing

AI Video Upscaler+ is designed around local video processing.

The official product page states that the AI models run on the user's PC and that video processing does not require uploading the user's video to a cloud video-processing service.

```text
User video -> Windows PC -> AI processing -> User output
```

Local video processing should not be confused with zero network communication. Updates, Microsoft Store operations, telemetry or other application services should be documented separately if applicable.

For current privacy terms, use the official website.
